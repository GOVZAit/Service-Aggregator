# Техническое задание: «995» — сервис заказа услуг

## 1. О проекте

**Название:** 995
**Тип:** Маркетплейс бытовых и профессиональных услуг
**Регион:** г. Грозный, Чеченская Республика (с возможностью масштабирования)
**Язык интерфейса:** русский
**Платформа:** мобильный веб (PWA-ready), адаптивная вёрстка под десктоп

**Цель:** Связать клиентов с местными мастерами/исполнителями для заказа услуг (сантехника, электрика, уборка, ремонт, красота, авто, доставка, репетиторы и др.).

## 2. Роли пользователей

### 2.1. Клиент
- Ищет и заказывает услуги.
- Просматривает каталог мастеров, фильтрует по категории, району, рейтингу.
- Создаёт заявки (как направленные конкретному мастеру, так и «автопоиск» — широковещательная заявка).
- Звонит, пишет в чат, оставляет отзывы.

### 2.2. Исполнитель (мастер)
- Регистрируется, заполняет профиль (имя, опционально — название бренда/компании, фото, описание, категория, услуги, портфолио).
- Управляет доступностью (онлайн-статус, режим звонков, рабочие часы).
- Принимает входящие заявки от клиентов и из общей ленты автопоиска.
- Ведёт активные/завершённые заказы, видит статистику (просмотры, заказы, доход).

### 2.3. Администратор *(планируется)*
- Модерация мастеров (верификация, выдача статуса «ТОП»).
- Модерация отзывов и жалоб.
- Управление категориями и районами.

## 3. Функциональные требования

### 3.1. Аутентификация
- Регистрация: имя + телефон + пароль + роль (клиент/исполнитель).
- Вход по телефону + паролю.
- Сессии (express-session, secret в env).
- Хеширование пароля (bcrypt).
- Автоматический редирект по роли после входа: клиент → `/`, исполнитель → `/master`.
- Защита маршрутов (RoleGuard): исполнитель не попадает на клиентские страницы и наоборот.

### 3.2. Главный экран клиента (`/`)
- Шапка: выбор района (Грозный + 5 районов через bottom-sheet), аватар.
- Большая поисковая строка (52px).
- Категории — горизонтальная лента чипов с эмодзи и иконками (8 категорий).
- Баннер «Нужен мастер срочно?» → запуск автопоиска.
- Список рекомендуемых мастеров с фильтрацией по выбранному району.

### 3.3. Карточка мастера
- Аватар с зелёной точкой онлайн-статуса.
- Опциональный бейдж бренда/компании (Building2 + название) — над именем.
- Имя, бейджи «ТОП» (золотая корона) и «Проверен».
- Категория услуг.
- Большой бейдж рейтинга (звезда + число + кол-во отзывов).
- Цена «от X ₽» в правом верхнем углу.
- Превью портфолио — 3 миниатюры.
- Район + расстояние, время отклика.
- Кнопка «избранное» (сердце).

### 3.4. Профиль мастера (публичный)
- Полная карточка: аватар, бренд, имя, верификация, категория, рейтинг, описание, район, время отклика.
- Статистика: количество заказов, рейтинг, цена.
- Вкладки: Услуги, Портфолио, Отзывы.
- Кнопки: «Написать», «Позвонить» (с учётом callMode), «Записаться» (модалка бронирования).
- Чат с мастером.

### 3.5. Система звонков (callMode)
- `always` — кнопка активна 24/7.
- `schedule` — активна только в рабочие часы.
- `online_only` — активна только пока мастер в онлайне.
- `disabled` — звонки отключены, остаётся только чат.
- Клиент видит подсказку о статусе («Офлайн», «Принимает звонки 09:00–18:00» и т. п.).
- Двухступенчатый клик: первый показывает номер, второй открывает `tel:`.

### 3.6. Заявки (автопоиск)
- Wizard в 3 шага: категория → описание + бюджет → адрес.
- `POST /api/requests` сохраняет заявку.
- Заявка видна **всем** мастерам соответствующей категории.
- Первый принявший мастер получает заказ.
- Новые заявки в начале списка `/api/requests`.

### 3.7. Заказы клиента (`/orders`)
- Список заказов со статусами: `pending`, `in_progress`, `completed`.
- Просмотр деталей, возможность оставить отзыв после завершения.

### 3.8. Городские службы (`/city`) и контакты (`/contacts`)
- Каталог организаций (полиция, скорая, банки, отели, АЗС, нотариусы и др.).
- Карточка: тип, название, телефон, **район + расстояние** (с иконкой Navigation), адрес, часы.
- Поиск, фильтрация по категориям.
- Переключатель «Список / Карта».
- Действия: позвонить, маршрут, сайт.

### 3.9. Интерфейс исполнителя
- **`/master`** (Дашборд):
  - Переключатель онлайн-статуса.
  - Статистика дня: просмотры, заказы, доход.
  - Лента новых входящих заявок (автопоиск).
  - Подсказки и советы.
- **`/master/orders`** — три вкладки:
  - **Новые** — принять/отклонить.
  - **Активные** — позвонить клиенту, завершить.
  - **Завершённые** — с отзывами клиентов.
- **`/master/profile`** — редактор профиля:
  - Аватар, имя, телефон.
  - Описание (О себе).
  - **Название компании/бренда** (опционально).
  - Категория услуг (выбор).
  - Доступность: callMode + рабочие часы.
  - Список услуг с ценами.
  - Сетка портфолио + загрузка фото.
  - Тема (тёмная/светлая).
  - Выход.
- Нижняя навигация: 3 вкладки (Главная / Заявки / Профиль).

## 4. Модель данных

```ts
Category { id, name, iconName, emoji, color }
District: 'Все районы' | 'Заводской' | 'Ленинский' | 'Октябрьский' |
          'Старопромысловский' | 'Шейх-Мансуровский'

Master {
  id, name, category, categoryId,
  rating, reviews, price, avatar, verified,
  distance, responseTime, completedOrders,
  description, portfolio[], services[],
  phone?, callMode, workingHours, isOnline,
  district?, topMaster?,
  companyName?           // опциональный бренд
}

Service { name, price }

ServiceRequest {
  id, title, category, description,
  budget, location, postedAt, responses, user
}

Order { id, title, masterId, status, date, price }

ChatMessage { id, text, sender, time }

AuthUser {
  id, name, phone, passwordHash,
  role: 'client' | 'master', createdAt
}
```

## 5. API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/categories` | Список категорий |
| GET | `/api/masters` | Список мастеров (фильтры: `categoryId`, `search`) |
| GET | `/api/masters/:id` | Мастер по id |
| GET | `/api/requests` | Список заявок (новые сверху) |
| GET | `/api/requests/:id` | Заявка по id |
| POST | `/api/requests` | Создать заявку (автопоиск) |
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| GET | `/api/auth/me` | Текущий пользователь |
| POST | `/api/auth/logout` | Выход |

## 6. Технологический стек

### Фронтенд
- React 18 + TypeScript
- Vite (сборка, HMR)
- Wouter (роутинг)
- TanStack Query v5 (серверное состояние)
- Tailwind CSS + CSS-переменные (тема)
- shadcn/ui (на Radix UI)
- react-hook-form + Zod
- lucide-react (иконки)

### Бэкенд
- Node.js + Express (TypeScript, ESM)
- express-session + connect-pg-simple
- bcryptjs (хеширование)
- Zod + drizzle-zod (валидация)

### База данных
- PostgreSQL.
- Drizzle ORM.
- Схемы разделены между `/shared/schema.ts` и специализированными schema-модулями.
- Применение схемы: `npm run db:push`.
- Пользователи, сессии, заявки, отклики, заказы, отзывы, чаты, избранное, push-подписки, provider-профили, справочники и admin audit хранятся постоянно в PostgreSQL.
- Seed-каталог мастеров остаётся fallback-данными в коде; новые мастера и организации хранятся в PostgreSQL.

### Инфраструктура
- Production: собственный Linux-сервер за nginx.
- Домен: `govza.pro`.
- HTTPS + reverse proxy.
- GitHub Actions: typecheck/build CI и автоматический production deploy.
- PWA: Service Worker, offline fallback, Web Push, автоматическое обновление установленного приложения.

## 7. Дизайн-система
- Mobile-first.
- Типографика: Inter.
- Шкала отступов: 2/4/6/8/12/16/20/24.
- Скругления: rounded-xl/2xl.
- Hover/active elevation на карточках.
- Поддержка светлой и тёмной темы.
- Цветовая схема — мягкая, в духе Airbnb / Linear / Thumbtack.

## 10. Нефункциональные требования
- **Производительность:** TTI ≤ 3 с на мобильном 4G.
- **Доступность:** контраст AA, alt у изображений, aria-label на иконочных кнопках.
- **Безопасность:** хеширование паролей, защита от XSS (React escape), валидация всех входов через Zod, HTTPS-only cookies.
- **Адаптивность:** mobile-first, корректное отображение от 320px до 1920px.
- **SEO:** уникальные `<title>` и `<meta description>` на ключевых страницах.

## 11. Метрики успеха (KPI)
- DAU / MAU.
- Количество регистраций мастеров и клиентов.
- Конверсия «просмотр карточки → заявка».
- Среднее время ответа мастера.
- Процент завершённых заказов (vs отменённых).
- Средний рейтинг мастеров.
- Retention 1/7/30 день.
