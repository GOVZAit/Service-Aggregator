# Диагностика расхождения production-схемы

Первая публикация PR61 остановлена защитой совместимости на таблице orders. Run 36233974216. Автоматическая миграция не выполнялась. Нельзя объявлять новую панель опубликованной по одному слиянию PR.

Уточнение gate: сначала создаётся и проверяется приватная копия существующей БД; затем выполняется прежняя строгая READ ONLY проверка всех 34 таблиц. При расхождении журнал содержит только tableExists и отсутствующие имена колонок из открытого ORM inventory, без пользовательских строк, значений, паролей или токенов. Ошибка по-прежнему останавливает публикацию. Диагностика не исправляет схему и не ослабляет проверку.

Это меняет порядок шагов, описанный в release-safety.md: backup теперь выполняется до проверки совместимости. Конкретные расхождения нужно изучить и согласовать отдельно; принудительный push и удаление таблиц запрещены. Существующая версия сервиса должна быть отдельно проверена после остановленного выпуска.
